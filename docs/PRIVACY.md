# 隐私说明

## 本地优先

行迹用于保存高度敏感的个人位置与移动历史。项目默认采用本地优先设计：

- 不要求注册账户。
- 不连接行迹自有服务器。
- 不包含广告、分析 SDK 或遥测。
- 不会上传行程、地点、备注或统计结果。
- 省级地图随应用打包，不请求在线地图服务。

安装依赖或下载 Release 需要访问软件分发服务，但应用运行期间不依赖这些网络请求。

## 数据位置

- 浏览器数据位于当前浏览器配置的 `localStorage`。
- macOS 数据位于 `~/Library/Application Support/行迹/journeys-v1.json`。
- iOS 数据位于系统管理的 App 私有沙盒。

三者相互独立，不会自动同步。清除浏览器站点数据、删除应用沙盒或主动删除 JSON 文件会造成相应端的数据丢失。

## 导入与导出

导出的 JSON 包含完整位置历史，应视为个人敏感文件。用户应自行决定保存位置、备份方式和访问权限。

导入会完整替换当前端数据。应用不会把导入文件复制到源码目录，也不会写入其他运行端。

## 开源仓库边界

源码仓库以空数据启动，`.gitignore` 排除常见行程导出文件、构建产物和 Xcode 用户状态。贡献者不得在 Issue、测试、截图或 Pull Request 中提交真实个人轨迹。

如发现可能导致本地数据外泄的缺陷，请按照 `SECURITY.md` 私下报告。
